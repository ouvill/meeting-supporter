# ADR-019: ローカル音声認識と保存済み履歴への整理

- **Status**: Accepted
- **Date**: 2026-10-01
- **Partially supersedes**: ADR-009、ADR-010、ADR-013、ADR-016 の議事録生成と音声認識の提供範囲

## Context

会議中の聞き取りと返答支援を中心に、音声認識の選択肢と会議後の機能を整理する。
保存済みの会議記録は維持する。

## Decision

### 音声認識

- 音声設定はローカルの Whisper / ReazonSpeech を提供する。音声認識用の API キー、接続先、クラウドモデルの設定は提供しない。
- 以前のクラウド設定が残っていても接続しない。別の方式へ自動変換せず、設定からローカル方式を選び直すよう案内する。
- 未提供の認識方式や将来の提供予定は画面・製品仕様に表示しない。
- ローカル音声認識と返答生成用の API キー・Ollama・ACP はアカウントに依存させない。

### 議事録

- 議事録の新規生成・再生成・生成経路の割当を廃止し、Rust への移植対象から外す。
- 会話履歴、返答案、録音と保存済み議事録は履歴から閲覧できる。保存済み議事録の本文や DB 列を削除しない。
- 古い `ai.assignments.minutes` は無視し、設定やモデルの準備を要求しない。
- 会議の正常終了・中断にかかわらず、保存済み議事録があれば表示する。内容がなければ議事録欄は表示しない。

## Rejected Alternatives

- 未提供の方式を選択肢に残す案は、現在使える機能を判断しにくくするため採用しない。
- 旧設定を自動的にローカル方式へ変える案は、モデルの準備や動作条件が変わるため採用しない。
- 議事録生成の廃止と同時に保存済み本文を削除する案は、既存の記録を失うため採用しない。

## Consequences

会議後の振り返りは保存済みの記録を中心にする。
保存済みのクラウド設定を使っていた利用者には、ローカル方式の選択と準備が必要になる。
